# 🌦️ Weather Data Analyzer

A Python-based project that analyzes weekly temperature and rainfall data to generate a simple weather summary.

## 📌 Features

- Calculates average weekly temperature
- Finds the highest and lowest temperatures
- Identifies the hottest and coolest days
- Calculates total weekly rainfall
- Finds the days with the highest and lowest rainfall
- Calculates the weekly temperature range
- Counts the number of rainy days
- Classifies daily weather as Hot, Moderate, or Cool

## 🛠️ Technologies Used

- **Python 3**
- Lists and list methods
- `for` loops
- `if-elif-else` conditional statements
- Built-in functions such as `sum()`, `max()`, `min()`, and `len()`
- List indexing

## 🚀 Getting Started

### Prerequisites

Install Python 3 on your computer.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Weather-Data-Analyzer.git
   ```

2. Open the project folder:

   ```bash
   cd Weather-Data-Analyzer
   ```

3. Run the Python program:

   ```bash
   python weather_analyzer.py
   ```

   On some Windows systems, you may need to use:

   ```bash
   py weather_analyzer.py
   ```

## 💻 How It Works

The program asks the user to enter the temperature in Celsius and rainfall in millimeters for each day of the week.

It then processes the entered data and displays a weekly report containing temperature statistics, rainfall summaries, rainy-day counts, and daily weather classifications.

## 📚 Learning Objectives

This project demonstrates the practical use of Python fundamentals, including lists, loops, conditional statements, indexing, and built-in functions for basic data analysis.
